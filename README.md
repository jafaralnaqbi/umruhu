# عمره فيما أفناه

صفحة ويب عربية خفيفة لمحاسبة النفس ومتابعة العبادات والعادات الحسنة يومًا بيوم، مع إحصائيات.

إعداد: جعفر النقبي

## المزايا

- الفرائض الخمس بمستوياتها: في المسجد، في وقتها، متأخرة، قضاء، فاتت؛ مع السنن الرواتب وأذكار ختام الصلاة.
- أقسام النوافل والأذكار والصيام والأعمال الصالحة والعادات الحسنة، والبنود كلها قابلة للإضافة والتعديل والحذف والترتيب.
- أنواع التسجيل: إنجاز (تم / لم يتم)، وعدّاد بهدف، ومستويات؛ وجدولة يومية أو بأيام محددة أو بالأيام البيض.
- ملاحظة على أي بند في أي يوم، وخانات يومية لمحاسبة النفس مع سجلها.
- إضافة فروع مباشرة في قسمي الأعمال الصالحة والعادات الحسنة (حتى ١٠ فروع لكل قسم).
- إحصائيات أسبوعية وشهرية وتراكمية، ومقارنة بالفترة السابقة، وتفصيل الصلوات، وسلاسل الأيام المتتالية، وتقويم ملوّن بنسبة الالتزام.
- رابط إلى صفحة «متابعتي مع القرآن».
- تصدير البيانات واستيرادها بملف JSON، وتعمل دون إنترنت، ويمكن إضافتها إلى الشاشة الرئيسية للهاتف.

## الخصوصية

لا تحتاج الصفحة إلى حساب، ولا ترسل أي بيانات إلى خادم. تُحفظ التسجيلات في متصفح المستخدم (IndexedDB)، ولذلك يُنصح بتصدير نسخة احتياطية بين حين وآخر.

## البنية التقنية

موقع ثابت من ملف `index.html` واحد (HTML وCSS وJavaScript دون مكتبات خارجية)، مع `manifest.webmanifest` و`sw.js` للعمل دون اتصال.
